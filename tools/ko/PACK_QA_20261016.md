사용자가 제공한 기존 통합 ZIP을 갱신하는 작업이다. 게임 실행 코드·계정·온라인·퀘스트·저장 시스템을 수정하지 않는다. 최신 게임 소스 병합 실험과 튜토리얼 실행 코드 변경은 이 팩 전용 브랜치에 포함하지 않았다. 기존 `ko-online-qa-20261014` 브랜치의 모든 커밋을 보존했다.

## 실행·배포 범위

- 새 ZIP의 제작과 정적 검증을 완료했다. 사용자에게 제공한 원본 ZIP을 덮어쓰지 않았다.
- 게임 실행 파일이나 웹 게임을 새로 빌드하지 않는다. 팩만 갱신했으므로 최종 결과에 대한 게임 프로덕션 빌드·전체 게임 테스트는 수행 대상이 아니다.
- 실제 게임에 팩 설치, 한국어 전환, 계정 복구, 온라인 캐릭터, 퀘스트 알림, 저장·불러오기 및 모바일 표시 검증은 **미완료**다.
- 테스트용 번역팩 ZIP으로 제공 가능하다. 안정판 릴리즈 판단은 위 인게임 확인 후 해야 한다. GitHub Release 발행이나 main 병합은 수행하지 않는다.
